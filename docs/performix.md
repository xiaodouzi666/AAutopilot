# Optional Arm Performix workflow

Performix can add hotspot context to representative generic and KleidiAI runs. It is supporting
evidence, not the source of speed claims and not a setup requirement. Use the controlled prompt
in `07-performix-agent-prompt.md`, preserve the profiled commands, redact target identity, and
retain a project-owned change only after the normal benchmark improves without violating the
quality or safety gate. When unavailable, record the reason and continue with timing/RSS and
best-effort Linux `perf`.
